# World Region Layout

## Spielbarer Stand

| Region | Rolle | Vorhandene Struktur | Visual-Layer-Ergänzung |
|---|---|---|---|
| Finsterwald | Kapitel 1 und Rückkehr-Hub | Start, Haupt-/Nebenwege, Bach, Brücke, Ruine, Steinkreis, See, Hütte, Aussicht, Portale und Memory Sites | Tutorial-Schwelle, Wurzeltor, Eulen-Sitzpunkte, Prozessionstor, warmer Rastpunkt, junge Regenerationsinseln |
| Sonnenfelder | Optionales Nebenquest-Gebiet | West-Ost-Hauptweg, Moorabzweig, Mühle, Hof, Felder, Portale und Memory Site | Bewässerungslinie, Obstgarten, Sonnenruine, Schattenrastplatz und vergrabenes Fundament |
| Nebelmoor | Kapitelregion-Prototyp | Hauptweg, Tümpel, Steg-Erinnerung, Karren, Portale und Memory Site | erhöhte Stegroute, sichere Insel, versunkene Landmarke, Zuflucht, Totholzpassage und Gefahrenkante |

## Produktionsschablone je Region

Jede Region benötigt vor Art-Lock: Startpunkt, Hauptpfad, zwei Nebenpfade,
eine Abkürzung, Aussicht/Landmarke, Rätselareal, Gefahrenareal, ruhigen
Erzählbereich, Memory Site und gesicherten Übergang. Diese Rollen werden im
Builder durch benannte Gruppen sichtbar gehalten.

## Weitere kanonische Kapitelregionen

Die Game Bible nennt: Tal der verlorenen Wege, Ruinen von Arvenfall, Archiv
der Hüter, Rotsteinschlucht, Kristallhöhlen von Elaris, Versunkene Küste,
Schneefelder von Vael, Feld der Asche, Lautlose Zitadelle und Herz von
Elyndor. Für diese Regionen fehlen im Repository belastbare Layout-, Quest-
und Story-Beat-Dokumente. Deshalb werden keine vermeintlich kanonischen
Szenen erzeugt. Nächster sicherer Schritt ist je Region ein freigegebenes
Greybox-Sheet mit Maßstab, Übergängen, Kernmechanik und Memory-Beat.

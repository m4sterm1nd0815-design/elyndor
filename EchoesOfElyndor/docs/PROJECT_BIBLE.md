# Echoes of Elyndor
Version 1.0

## Vision

Echoes of Elyndor soll sich anfühlen wie eine Mischung aus

- Zelda: Tears of the Kingdom
- Zelda: Twilight Princess
- Elden Ring
- Ori
- Hob
- Tunic

ohne eines dieser Spiele zu kopieren.

Der Spieler soll ständig das Gefühl haben:

"Da hinten könnte noch etwas sein."

Neugier ist die wichtigste Spielmechanik.

---

# Designziele

Jeder Ort erzählt eine Geschichte.

Jede Höhle hat einen Grund zu existieren.

Jede Ruine besitzt Vergangenheit.

Jedes Rätsel fühlt sich logisch an.

Belohnungen sind bedeutungsvoll.

Keine sinnlosen Sammelaufgaben.

# Keine Features

Kein Battle Pass

Keine Mikrotransaktionen

Kein Echtgeldshop

Kein Pay2Win

Kein Lootbox-System

---

# Spieler

Der Spieler besitzt keine Klasse.

Er entwickelt sich über:

Waffen

Relikte

Erinnerungen

Runen

Fähigkeiten

---

# Erinnerungen

Die wichtigste Ressource.

Erinnerungen sind Energie.

Sie öffnen Wege.

Sie lösen Rätsel.

Sie verändern die Welt.

---

# Herzsystem

Herzen statt Lebensbalken.

Zusätzliche Herzen müssen verdient werden.

---

# Waffen

Alle Waffen können verbessert werden.

Keine Wegwerfwaffen.

Legendäre Waffen besitzen Geschichte.

---

# Welt

Die Welt besteht aus mehreren Regionen.

Jede Region besitzt:

eigene Musik

eigene Vegetation

eigene Gegner

eigene Architektur

eigene Geschichte

eigene Quests

eigene Geheimnisse

---

# Dungeons

Jeder Dungeon

neue Mechanik

eigener Boss

eigene Musik

eigene Identität

eigene Belohnung

---

# Bosskämpfe

Keine HP-Schwämme.

Jeder Boss besitzt:

Mechaniken

mehrere Phasen

Lore

Belohnungen

# Rätsel

Rätsel entstehen aus der Welt.

Nicht aus Schaltern.

Vergangenheit und Gegenwart spielen zusammen.

Die Taschenuhr verändert Bereiche der Welt.

---

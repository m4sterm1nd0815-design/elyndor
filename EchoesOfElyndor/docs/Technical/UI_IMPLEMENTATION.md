# UI Implementation – Foundation

## Enthalten
- HUD-Grundlage für Leben, Ausdauer und Erinnerungsenergie
- acht visuelle Quickslots
- Fokusdarstellung über Unity EventSystem
- Editor-Befehl zum Erzeugen eines HUD-Prefabs
- Screenshot-Baselines in 1080p und 4K

## Unity-Menüs
- `Elyndor > UI > Create HUD Foundation`
- `Elyndor > Presentation > Capture HUD Baselines`

## Integration
1. Unity kompilieren lassen.
2. HUD-Prefab erzeugen.
3. Prefab unter einen Screen-Space-Canvas setzen.
4. Serialized References im Inspector zuweisen.
5. Screenshot-Baselines erstellen.
6. Noch keine Gameplay-Systeme doppelt anlegen.

## Offene Punkte
- finale Grafiken
- Input-Actions
- echte Ressourcenanbindung
- Quickslot-Logik
- Controller-Glyphen

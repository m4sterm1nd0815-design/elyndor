# Roadmap

## Aktuelles Ziel
Ein stabiler Vertical Slice von Kapitel 1 im Finsterwald.

## Phase 0 – Stabilisierung
- Repository- und Unity-Stand prüfen
- Compilerfehler beseitigen
- Input vereinheitlichen
- Tests und Screenshot-Baselines

## Phase 1 – Kernspiel
- Bewegung und Kamera
- Interaktion und Erinnerungsuhr
- Kampf und Ressourcen
- Inventar, Ausrüstung, Quickslots
- Quests, Lore und Savegame

## Phase 2 – Vertical Slice
- Finsterwald-Route und Landmarken
- Aren und Link
- Erinnerungsrätsel
- Hauptquest in vier Abschnitten
- Gegner plus Elitevariante
- sichtbare Weltveränderung
- finaler UI-, Audio-, Licht- und VFX-Pass

## Definition of Done
Ein Feature kompiliert, ist getestet, dokumentiert, speicherbar und mit QA- oder Screenshot-Nachweis belegt.

# UI Guidelines

## Stil
Dunkle transparente Stein-/Glasflächen, feine warme Goldlinien und zurückhaltendes türkisfarbenes Erinnerungslicht.

## Bereiche
HUD, Inventar, Ausrüstung, Quickslots, Questlog, Lore-Kodex, Weltkarte, Einstellungen und Save/Load.

## Bedienung
- Controller First
- vollständige Maus-/Tastaturbedienung
- sichtbarer Fokus
- keine Navigations-Sackgassen
- zuverlässiges Zurück-Verhalten

## Barrierefreiheit
- UI-Skalierung 75–175 %
- große Schrift
- hoher Kontrast
- reduzierte Bewegung
- Zustände nicht ausschließlich über Farben
- Tooltips ohne Abschneiden

## Screenshot-Baselines
720p, 1080p, 1440p, 4K, 21:9, 175 % UI-Skalierung, Controller-Fokus und reduzierte Bewegung.

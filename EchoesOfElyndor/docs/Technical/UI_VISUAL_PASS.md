# UI Visual Pass 1

## Ziel

Die funktionale HUD-Grundlage wird in ein konsistentes Elyndor-Erscheinungsbild überführt.

## Änderungen

- kompakter Vitals-Rahmen
- klare Bezeichnungen für Leben, Ausdauer und Erinnerung
- dunkle halbtransparente Flächen
- warme Goldrahmen
- türkisfarbene Erinnerungsakzente
- kleinere und besser proportionierte Quickslots
- visuelle Icon-Platzhalter
- zentrales `ElyndorUITheme`-Asset

## Unity

Ausführen:

`Elyndor > UI > Rebuild Styled HUD Foundation`

Danach das vorhandene HUD-Objekt in der Szene löschen und das neu erzeugte Prefab unter den Canvas ziehen.

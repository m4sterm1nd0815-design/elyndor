# Vision Guard

## Unverhandelbar
- Die Welt ist die Hauptfigur.
- Neugier ist der wichtigste Antrieb.
- Gameplay kommt vor Lore-Erklärung.
- Die Erinnerungsuhr zeigt Möglichkeiten, niemals fertige Lösungen.
- Keine bedeutungslosen Fetch-Quests.
- Jede größere Quest verändert sichtbar etwas.
- Jede Region besitzt eigene visuelle, akustische und spielerische Identität.
- Gegner sind keine bloßen Lebenspunkt-Säcke.
- Controller First, PC vollständig unterstützt.
- Kein Zustand wird nur über Farbe vermittelt.
- Keine Mikrotransaktionen, Lootboxen oder Battle-Pass-Systeme.
